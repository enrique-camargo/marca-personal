# Reglas de Trabajo para el Proyecto (AGENTS.md)

## 📌 Regla de Oro: Mantenimiento Continuo de BITACORA_SOLUCION.md
Cada vez que se agregue, modifique, elimine o actualice cualquier elemento en este repositorio:
1. **Actualizar [BITACORA_SOLUCION.md](BITACORA_SOLUCION.md):**
   - Registrar la versión y fecha en la sección `## 📜 5. HISTORIAL DE CAMBIOS Y VERSIONES (CHANGELOG)`.
   - Detallar con precisión qué se agregó, modificó o corrigió.
   - Si se modificó la arquitectura, diseño, estructura de módulos o flujo de la aplicación, actualizar las secciones descriptivas correspondientes en la bitácora.
2. **Preservar la Identidad Visual:**
   - Mantener el diseño *Dark Tech & Sports Strategy (Hypermotion Edition)*: `slate-950`, `cyan-400`, `emerald-400`, tipografías Outfit / Space Grotesk / JetBrains Mono.
3. **Control de Versiones:**
   - Tras validar los cambios, realizar commit descriptivo y push a `origin/main` en GitHub.
